# TANEM — шаблон сайта мастера по волосам

Это зафиксированный шаблон на основе production-сайта [Юлии Ролевой](https://julia.tanem.ru/). Внешний вид, адаптивность, категории услуг, прайс по длине волос, галерея, отзывы и мобильная навигация перенесены без упрощения.

## Как сделать следующий сайт

1. Создать новый репозиторий из этого шаблона.
2. Изменить только `site-data.mjs`: данные мастера, контакты, ссылки, адрес, категории, услуги, варианты цен, отзывы и SEO.
3. Заменить фотографии внутри `public/assets/yulia/` и при необходимости изменить `assetBase` в `site-data.mjs`.
4. Выполнить `npm ci && npm test`.
5. Проверить сайт визуально на телефоне и компьютере и только затем публиковать.

Обычная услуга содержит одну цену. Услуга с разной стоимостью для коротких, средних и длинных волос содержит массив `variants`. Количество услуг может отличаться; категории остаются такими же чёткими, как на сайте Julia.

## Главное правило

Для нового клиента нельзя редактировать `app/` и CSS ради подстановки контента. Вся клиентская информация находится в `site-data.mjs`, а все клиентские изображения — в одной папке assets. Изменения дизайна сначала проверяются здесь как новая версия шаблона и только потом переносятся на новые сайты.

## Команды

```bash
npm ci
npm run dev
npm test
npm run lint
```

GitHub Actions проверяет данные и собирает статический сайт. Для первой публикации демонстрации нужно один раз выбрать `Settings → Pages → Source → GitHub Actions`; после этого тот же workflow публикует сайт автоматически.
